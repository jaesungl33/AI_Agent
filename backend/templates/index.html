Tank War Code & GDD Analysis System

✅ Backend Running

This is the backend API for AI-powered analysis of Tank War game design documents and codebase. The system provides intelligent chat, document processing, and automated code-GDD coverage analysis.

🚀 API Endpoints

  • GET /health - Health check
  • GET /api/workspaces - List workspaces
  • GET /api/documents - Get documents
  • POST /api/chat - Chat with AI (requires JSON payload)
  • POST /api/index - Index codebase

📊 Features

  • 🤖 Intelligent chat about Tank War GDDs
  • 🔍 Codebase search with @codebase queries
  • 📄 Document processing and analysis
  • ✅ Automated code-GDD coverage analysis
  • 🏢 Multi-workspace support
